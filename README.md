# 證照整理

單一 HTML 檔的證照管理工具：匯入 104 匯出的 Excel、名稱歸併、到期與缺漏提醒、回訓紀錄、人員名單（可標離職）、紙本位置記錄、選擇證照匯出。

## 使用
直接開啟 `index.html`，或用 GitHub Pages 發佈。

## 資料存放
所有資料只存在使用者自己瀏覽器的 localStorage，**不會上傳到 GitHub 或任何伺服器**。
換電腦、換瀏覽器、換網址都看不到舊資料，請用「匯入／匯出」頁的「完整備份」搬移。

## 注意
- 請勿把含姓名、身分證字號的 Excel 或備份檔放進這個 repo。
- Repo 設為 Public 時，網頁程式碼是公開的，但裡面沒有任何人員資料。
